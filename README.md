# Projeto Criptomoedas

Projeto do curso React Js com TypeScript do zero ao avançado na prática.

## Execução do Projeto

- Adicionar um arquivo .env na raiz do projeto
- Adicionar a a chave da API de criptomoedas (https://pro.coincap.io/dashboard), exemplo:

```js
VITE_COINCAP_API_KEY=SUA_API_KEY
```

- Console


```js
npm run dev
```
